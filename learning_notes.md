# Introduction to AI & Python — Learning Notes

## 1. What is Artificial Intelligence?

Artificial Intelligence (AI) is a field of computer science that focuses on creating systems that can perform tasks that normally require human intelligence.

Examples:
- Voice assistants
- Recommendation systems
- Image recognition
- Language translation
- Fraud detection

## 2. What is Machine Learning?

Machine Learning (ML) is a subset of AI in which computers learn patterns from data and use those patterns to make predictions or decisions.

Examples:
- Spam email detection
- Movie recommendations
- Predicting house prices
- Customer churn prediction

## 3. AI vs ML vs Deep Learning

- AI is the broad field of making machines perform intelligent tasks.
- ML is a subset of AI that learns patterns from data.
- Deep Learning is a subset of ML that commonly uses multi-layer neural networks.

Simple relationship:

AI
└── Machine Learning
    └── Deep Learning

## 4. Real-World AI Applications

### Healthcare
AI can assist with medical image analysis, prediction, and administrative tasks.

### Education
AI can support personalized learning, feedback, and educational tools.

### Banking
AI is used for fraud detection, risk analysis, and customer-service automation.

### Transportation
AI can be used in route planning, driver-assistance systems, and traffic prediction.

### Entertainment
Recommendation systems can suggest movies, music, or videos based on user behavior.

## 6. Variables

A variable stores a value.

Example:
```python
name = "Bhavana"
age = 20
```

## 7. Lists

A list stores multiple values in one variable.

Example:
```python
fruits = ["Apple", "Banana", "Mango"]
```

## 8. Loops

Loops repeat a block of code.

For loop:
```python
for number in range(1, 6):
    print(number)
```

While loop:
```python
count = 1
while count <= 5:
    print(count)
    count += 1
```

## 9. Functions

A function is a reusable block of code.

Example:
```python
def add_numbers(a, b):
    return a + b
```
